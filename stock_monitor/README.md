# 保有株 売りライン監視

SBI証券(NISA)で保有する米国株について、毎朝ルールに沿ってチェックし、変化があった日だけスマホに通知する。
**注文は出さない。** 通知を見て、本人がSBIで操作する。

## ルール
- 売りライン = 取得後の最高終値 − 3 × ATR(22日)。一度上がったら下げない(ラチェット)
- 銘柄ごとの値動きの大きさに合わせて幅が変わる(NVDA約13%、P約30%)
- 根拠: Chandelier Exit (Le Beau)、トレーリング幅15〜25%が良好という米国株の検証、Kaminski & Lo (2014)

## 通知
| 種類 | 条件 |
|---|---|
| 🔴 売りライン割れ | 終値が売りラインを新たに下回った |
| ⬆️ 売りライン上昇 | 5営業日前より5%以上上がった → SBIの逆指値を変更 |
| 🟢 プラス転換 | 含み損だった銘柄が取得単価を上回った |
| 📅 決算接近 | 決算の3日前から |
| 🔁 再エントリー候補 | 売却済み銘柄が50日線を上抜け |
| 🌐 相場の変化 | SPYが200日線を上抜け/下抜け |
| ⚠️ データ未更新 | 前の米国取引日の終値がまだ取れていない(祝日は config の market_holidays で除外) |
| 週次(土曜) | 全銘柄の状況、集中度(1銘柄20%超)、データ取得の正常性 |

## 実行時刻
日本時間 火〜土 7:20。冬時間では米国の引けから1時間20分後なので、データが未更新のことがある。その場合は ⚠️ で知らせ、ジョブが待って再実行する。

## 売買したら
`config.json` を更新する。売った銘柄は `holdings` から `sold` に移す(例: `{"symbol": "P", "date": "2026-11-10", "price": 97.0}`)。

## 実行
```
python3 monitor.py --mode daily
python3 monitor.py --mode weekly
python3 monitor.py --mode weekly --asof 2026-08-24   # 過去日付で検証
```
データは Tiingo。APIキーはクラウド環境のプロキシが自動で付与する。

## ニュース・届け出の確認(news.py)
- 毎朝: SECの臨時報告(8-K)の重大項目(役員の交代、新株の発行、決算の訂正など)と増資の届け出を拾う
- 急落した銘柄(1日-8%以上): `--news-for` でその銘柄の見出しも確認し、会社固有の理由か見分ける
- 週次: 各銘柄の主なニュースの見出しを添える
- 売買の合図には使わない(話題の株を買うと成績が落ちる: Barber & Odean 2008)

## 新しい候補の発見(discover.py)
SECの全上場企業の四半期データで、前の四半期には条件を満たさず、最新の四半期で初めて満たした会社を拾う。
- 若手: 上場5年以内、売上成長20%以上、営業利益率10%以上
- 確立企業(数倍狙い): 上場年数は問わない、年売上10億ドル以上、成長15%以上、営業利益率15%以上
- 直近4四半期の合計でも確認し、1四半期だけの好調や一時金を除く(`--quarter-only` で外せる)
- 創業者経営かどうかは自動では判定できない(要確認)
- `--mode full` で条件を満たす全社の一覧
